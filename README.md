# CodeQuest-UZ

Dasturlash asoslarini o‘rganish uchun kichik interaktiv quiz prototipi.

## Hozirgi imkoniyatlar

- HTML, CSS va JavaScript asoslariga oid ko‘p tanlovli savollar.
- Javob tanlanganda darhol izoh va to‘g‘ri/noto‘g‘ri natijani ko‘rsatish.
- XP va daraja hisobini yuritish.
- Savolga qayta javob berib XP ni takror yig‘ishni cheklash.
- Quiz progressi va yig‘ilgan XP ma’lumotlarini brauzer `localStorage` xotirasida saqlash.

## Ishga tushirish

`index.html` faylini brauzerda oching yoki GitHub Pages orqali joylashtiring. Build vositasi va API kaliti talab qilinmaydi.

## MVP chegaralari

Hozirgi savollar to‘plami kichik demo. To‘liq kurs, kod muharriri, avtomatik kod tekshirish, o‘qituvchi paneli, akkaunt va serverda progress sinxronlash hali ulanmagan.

## Keyingi bosqich

Mavzular bo‘yicha katta savollar banki, bosqichma-bosqich darslar, kod yozish mashqlari va o‘quvchi progressi uchun akkaunt.
